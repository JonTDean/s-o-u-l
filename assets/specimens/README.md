# Published Orbium fixture

Orbium bicaudatus, Bert Wang-Chak Chan, MIT License (adjacent license).
Source: https://github.com/Chakazul/Lenia/blob/adfc542939266de7f4bb7ebb552e8499701ee107/Jupyter/Lenia.ipynb
The 20×20 `load_cells(0)` density array is unmodified, centered in a 64×64 periodic
XY plane. R=13, peaks=[1], mu=0.15, sigma=0.014, dt=0.1. Both kernel and
growth use the notebook's default polynomial (quad4) functions. No upscaling.
SOUL stores this plane at Z=4 in its volume; Z planes do not interact in this model.
The separate Gaussian/shell XYZ models retain their original semantics.
