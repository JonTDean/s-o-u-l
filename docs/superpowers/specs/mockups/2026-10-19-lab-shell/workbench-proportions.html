How these behave
  • Colour is set per channel: five palette swatches plus a custom picker. Default is amber.
  • Continuous families (Lenia, HPP density) get a ramp generated from the chosen colour. The Lenia voxel shader takes it as a uniform; that is renderer work in this sub-project.
  • Citation: every specimen ships a caption, a one-line explanation and a reference with a DOI. Clicking the DOI opens it in the system browser.
  • Presenter mode uses the caption as its subtitle.
